# AttendEase - Attendance Management System

AttendEase is a web-based Student Attendance Management System.

## Features
- Student Management
- Subject Management
- Attendance Tracking
- Attendance Percentage Calculation
- Attendance Reports
- Dashboard

## Technologies Used
- React
- JavaScript
- CSS
- Vite
- REST API Integration

## How to Run

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm run dev
```

Build the application:

```bash
npm run build
```
